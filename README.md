Project Name : Bazar Dor App

Description : 
A Bangla-based product price comparison platform that helps users explore product prices, compare market prices, and manage their profiles. Users can create an account, sign in with email or Google/GitHub, view product information, and update their profile.

Technologies :

1. Next.js
2. React
3. Better-Auth
4. TypeScript
5. Tailwind CSS
6. React Toastify
7. React Icons
8. daisyUI

Key Features
1. Product Price Comparison – Compare prices from different markets to find better deals.
2. Detailed Product Information – View product details, prices, and market information.
3. User Authentication – Secure sign-up and sign-in with email, Google, or GitHub.
4. Profile Management – View and update personal profile information.
5. Bangla-Friendly Interface – Simple and user-friendly interface designed for Bangla-speaking users.
